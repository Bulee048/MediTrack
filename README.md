# MediTrack – Appointment Booking and Queue Management for Government Hospital OPDs

IT3060 Human Computer Interaction University Project.

## Project Structure
- `client/` - Frontend built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.
- `server/` - Backend built with Node.js, Express, TypeScript, and MongoDB (Mongoose).
- `docs/` - Project documentation and specifications.

## Setup & Running
See instructions in `client/README.md` and `server/README.md`.
